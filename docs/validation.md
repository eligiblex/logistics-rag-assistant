# 验证记录

日期：2026-10-10。环境：Windows、Python 3.12、仓库 requirements.txt 中的依赖版本。

## 已完成

- 18 项 Python 离线测试通过：配置覆盖、文档加载、稳定 ID、真实 Chroma 的重复同步与旧块移除、检索与引用一致性、无资料跳过生成、API 校验、SSE、错误隐藏、后台刷新状态。
- Node 测试通过：对完整事件流遍历所有分包大小，覆盖中文、emoji、换行、CRLF、截断事件。
- 本机 Ollama + nomic-embed-text 成功建立 5 个示例知识块；重复同步后仍是 5 个，无重复增加。
- Qwen2.5 7B 成功回答“运单应包含哪些基本信息”，返回 5 个来源片段；一次观测约 5.23 秒。
- 同一模型完成 ABC 库存分类的真实流式回答，收到 120 个文本增量和完成事件；一次观测约 4.09 秒。
- 实际启动 Uvicorn 后，/api/health 返回就绪，/api/query 成功回答 WMS 问题并返回来源；静态 SSE 脚本可访问。
- 8 个教学问题的关键词检索检查：Top-1 命中 3/8，Top-3 命中 6/8，Top-5 命中 8/8。这里只有 5 个知识块，Top-5 相当于全取，结果不代表高质量排序，更不能写成答案准确率 100%。

这些耗时来自单机单次冒烟验证，生成上限设为 160 token，不是压测、SLA 或默认配置的性能承诺。小型示例只有 5 个块，默认 Top-5 接近全量上下文，不适合作为大规模检索能力证明。
